# Human Resources Dashboard – Data Analytics Project

## 📌 Project Overview
![image](https://raw.githubusercontent.com/user/repo/main/hr-summary.jpg)
This project is an interactive **Human Resources Analytics Dashboard** designed to transform raw HR data into meaningful business insights.  
The dashboard helps HR teams and decision-makers monitor workforce trends, employee demographics, hiring performance, salary distribution, and departmental statistics in a visually efficient way.

The goal of this project is to demonstrate practical **Data Analytics**, **Data Visualization**, and **Business Intelligence** skills using a modern HR dataset.

---

# 🎯 Objectives

- Analyze employee demographics and workforce composition
- Monitor hiring and termination metrics
- Visualize department performance and employee distribution
- Explore salary trends across education levels and job positions
- Build an intuitive and visually clean dashboard for HR reporting

---

# 📊 Dashboard Features

## ✅ Workforce Overview
- Active employees count
- Hired employees
- Terminated employees
- Department distribution

## ✅ Demographics Analysis
- Gender distribution
- Education levels
- Age groups
- Education vs performance analysis

## ✅ Salary & Income Insights
- Salary by education level
- Salary by gender
- Position salary comparison
- Age vs salary correlation

## ✅ Geographic Visualization
- Employee location analysis
- Branch comparison
